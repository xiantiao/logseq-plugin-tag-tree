# Tag Tree Settings / Tag Tree 设置

All settings are managed in Logseq's native plugin settings panel: **Settings → Plugins → Tag Tree → Settings**.

所有设置均在 Logseq 原生插件设置面板中管理：**设置 → 插件 → Tag Tree → Settings**。

## Available Options / 可用选项

### Theme Style / 主题样式
- **Colorful / 彩色**（default）— vibrant tag backgrounds and colored elements / 鲜艳的标签背景与彩色元素
- **Simple / 简洁** — monochrome, minimal styling / 单色极简风格

### Keyboard Shortcut / 快捷键
- Opens the tag tree panel / 打开标签树面板
- Default: `mod+shift+t` (`Cmd+Shift+T` on macOS, `Ctrl+Shift+T` on Windows/Linux)
- Examples: `alt+t`, `cmd+alt+t`, `ctrl+shift+p`

### Auto Normalize Legacy Tags / 旧版层级标签自动规范化
- **On**（default）— legacy `#a/b/c` tags are rewritten to the inline form `a/b/#c` as you edit
- **Off** — legacy tags stay untouched; use the context-menu migration command to convert them in bulk
- **开启**（默认）—— 编辑时旧式 `#a/b/c` 自动改写为行内写法 `a/b/#c`
- **关闭** —— 保留旧写法，可通过右键菜单的迁移命令批量转换

## Notes / 说明
- Settings changes apply immediately; no restart needed / 设置即时生效，无需重启
- The panel follows Logseq's light/dark theme automatically / 面板自动跟随 Logseq 明暗主题
